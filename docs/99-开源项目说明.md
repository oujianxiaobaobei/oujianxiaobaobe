# 99 开源项目说明

> 依据《2026CRTC 参赛手册 V1.5》文档规范：如使用开源项目用于机器人制作及代码编写，应在文档末尾完整说明。

## 使用清单

| 部分 | 来源 | 说明 |
|---|---|---|
| STM32 HAL 库 | ST 官方（CubeMX 自动生成） | 版权归 ST，随 CubeMX 生成，作为底层驱动库 |
| CubeMX 初始化代码 | ST 官方工具生成 | `tim.c`、`gpio.c`、时钟配置等 |
| PS2 协议时序 | Sony 公开的 PS2 协议规格 | 参考了公开的 PS2 协议资料（9 字节帧、LSB 先行、采样时机），**代码自己实现** |
| 麦轮运动学公式 | 公开的机器人学教材公式 | 公开物理公式，**代码自己实现** |
| 电机驱动、速度映射、保护逻辑、电源方案 | 自研 | 完全自己写 |

## 声明

**本项目没有抄用其他开源项目的控制代码。** 使用的开源内容仅限：

1. **ST 官方 HAL 库与 CubeMX 生成代码**——作为 STM32 底层驱动，按 ST 许可证使用；
2. **公开协议与物理公式**——PS2 手柄协议是 Sony 定义的公开规格，麦轮运动学是公开的机器人学公式；我们参考协议/公式本身，所有应用代码（PS2 时序模拟、麦轮解算、速度映射、保护逻辑）均为自主编写。

## 代码仓库结构

```
TEST/
├── Core/
│   ├── Inc/                CubeMX 生成的头文件（main.h / tim.h / gpio.h）
│   └── Src/
│       ├── main.c           ★ 全部应用代码（自主编写）
│       ├── tim.c            CubeMX 生成的定时器初始化
│       ├── gpio.c           CubeMX 生成的 GPIO 初始化
│       └── stm32f1xx_it.c   中断向量
├── Drivers/STM32F1xx_HAL_Driver/   ST 官方 HAL 库
├── MDK-ARM/TEST.uvprojx    Keil 工程
└── TEST.ioc                CubeMX 工程文件
```
