# 04 电控 - SPI 与 PS2 手柄

> 培训所学。PS2 手柄不是 SPI，是它自己的 4 线同步串行协议。

## 物理层

DAT（输入，必须上拉）/ CMD（输出）/ CS-ATT-SEL（输出，低有效）/ CLK（输出）。用 GPIO 软件模拟时序。

## 帧格式（9 字节，LSB 先行）

- RX[0]=0x01，RX[1]=模式 ID（0x41 数字 / 0x73、0x79 模拟 / 0x0C 2.4G）
- RX[2]=0x5A 校验；RX[3][4] 按键（bit=0 表示按下）；RX[5..8] 摇杆（中位约 128）

## 时序要点

CMD 放数据 → CLK 拉低 → 延时 → **在 CLK 低电平期间读 DAT** → CLK 拉高 → 延时。早读晚读都会拿到错位数据（踩过坑）。

## 断联处理（安全底线）

手柄关机/掉模式时接收器仍回 0x41，摇杆全 0xFF。若照常计算会认为摇杆推满，车自己冲出去。判据不是"读到预期值"，而是"数据会不会随操作变化"。每轮检查 ID，不对立刻停车。

## 对频流程

接收器断电重上电 → 按住配对键 2~3 秒 → 手柄开机靠近 → 灯从"闪"变"常亮"即对上。
