# 05 电控 - 麦轮运动学解算

> 培训所学，也是最终用于小车的实现。

## X 型辊子排布公式

```
左前 = 前后 - 横移 + 自旋
右前 = 前后 + 横移 - 自旋
左后 = 前后 + 横移 + 自旋
右后 = 前后 - 横移 - 自旋
```

## 归一化

斜推摇杆时四轮计算值可能超过上限，直接下发会削顶导致走歪。取四轮绝对值最大值，超限就等比缩放——方向与比例不变，只整体降速。

## 斜 45° 平移原理

横移时左边两轮反转、右边两轮正转。每个轮子的推力沿辊子 45° 分解：横向分量叠加推动车横移，纵向分量左右互相抵消（车不前后动）。注意横移效率只有前进的约 70%。

## 自旋原理

自旋时左侧两轮正转、右侧两轮反转，四轮推力形成力偶，绕车体中心旋转。

## 踩坑：摇杆映射

TT 马达有启动死区电压（实测 48% 占空比时同批马达有的能起步有的不能），速度映射必须设下限 60%，否则推一点点时四轮有的转有的不转，车画歪。
