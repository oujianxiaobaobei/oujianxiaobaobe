# 03 电控 - FreeRTOS 与工程结构

> 培训所学 + 项目实际选型记录。

## 我们最终没用 FreeRTOS（裸机）

原因：
1. 任务量小，全部微秒级，单循环实时性够；
2. F103C8T6 RAM 仅 20KB，RTOS 每任务独立栈，开几个就紧张；
3. 裸机断点即调试；RTOS 出问题是调度问题，大一阶段排查不了；
4. 阻塞用计数器+状态机解决（如舵机每 20ms 写一次 CCR，不 sleep）。

**关键纪律**：主循环关键路径禁止 HAL_Delay，否则手柄变"肉"。

## 什么情况下会上 RTOS

加了 OLED 刷屏、串口协议解析、多传感器、舵机平滑插值，任务开始互相抢时间时。

## 工程结构（CubeMX + Keil）

Core/Src/main.c 为全部应用代码；tim.c/gpio.c 为 CubeMX 生成初始化；Drivers/ 为 ST 官方 HAL 库。详见 99-开源项目说明。
