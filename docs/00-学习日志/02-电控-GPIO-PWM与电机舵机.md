# 02 电控 - GPIO / PWM 与电机舵机

> 培训所学 + 实际参数。

## PWM 驱动电机

4 路 20kHz PWM（TIM3/TIM4）+ 4 个方向 GPIO，经 DRV8833 双 H 桥驱动 TT 马达（1:48）。7.4V 供电，PWM 限幅 90% 等效约 6.6V 防超压。

## 舵机控制

TIM2 通道 2，50Hz：PSC=71 → 1MHz 计数，ARR=19999 → 20ms 周期。脉宽 0.5~2.5ms 对应 0°~180°：`CCR = 500 + angle * 2000 / 180`。

**PWM 不能停**：舵机保持力来自持续 PWM，停通道会失力掉落。只改 CCR，不停通道。

**上电先回中位**：上电先写 1.5ms 中位脉宽等 200~300ms，否则会从未知位置猛甩打坏齿轮。

**角度限位**：机械行程不到 180°，软件夹在 10°~170° 防顶死堵转烧舵机。

## SG90 vs MG996R

MG996R 堵转约 2.5A，必须单独一路 ≥3A 降压供电；SG90 1A 降压够。舵机 5V 与逻辑 5V 必须分开，否则舵机冲击会拉塌板子电源（表现为莫名复位、手柄掉模式）。两路 5V 绝不能并联。
