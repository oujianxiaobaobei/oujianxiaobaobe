## 机电联调

### 功能描述

将机械结构与电控系统整合，完成整机的组装与联调，使底盘移动与方块串取抬升机构协同工作，实现"行进 → 串取 → 抬升携带 → 释放"的完整动作流程。

1. 第四周开始组装实操，将各 3D 打印件与电控器件装配到机架上；
2. 完成机械与电控的联合调试；
3. 反复测试整机动作，修正机构与参数，直至动作稳定。
